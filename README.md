# 시험 시간표

나이스 **학생편성현황** 엑셀로 고사 시간표를 짜고, 고사실·자습실 배치와 인쇄물(엑셀)을 만드는 프로그램입니다.
설치·인터넷이 필요 없고, 학생 정보는 이 컴퓨터의 브라우저 밖으로 나가지 않습니다.

## 내려받기 (사무실 PC)

**[⬇ exam-timetable.html 내려받기](https://github.com/cksgml0810/exam-timetable/releases/latest/download/exam-timetable.html)**

1. 위 링크를 눌러 파일을 저장합니다.
2. 저장한 `exam-timetable.html`을 더블클릭 → Chrome 또는 Edge로 열립니다.
3. 나이스에서 받은 학생편성현황 엑셀을 화면에 끌어다 놓으면 시작합니다.

## 다른 컴퓨터에서 이어서 작업
상단 **프로젝트 저장** → `.json` 파일을 옮긴 뒤 다른 PC에서 **프로젝트 열기**.
(작업 내용은 브라우저에 자동 저장되지만, 컴퓨터·브라우저가 바뀌면 이 파일로 옮겨야 합니다.)

## 사용 순서
1. 데이터 불러오기 — 시험 제외·편의반 학생 표시
2. 기초 정보 — 시험 일자·교시
3. 반 · 고사실 — 고사실 추가, 최대 수용, 자습 사용, 좌석 모양
4. 과목 확인
5. 평가 과목 — 동시 시험 가능 조합 확인
6. 시간표 작성 — 하루 최대/최소 과목 수로 자동 배치 → 직접 조정, 학생 부담 대시보드
7. 학생 배치 — 시험실을 한쪽으로 모으고 나머지는 자습실, 정원 초과 바로 고치기, 편의반 학생별 고사실 지정
8. 좌석 — 학번순/무작위, 5열×7석 등
9. 엑셀 출력 — 미리 보기 후 다운로드 (전체 시간표, 명렬표, 좌석배치도, 학급별·학생별 시간표, 봉투 라벨), 학생별 시간표 안내 문구
10. 골라서 인쇄 — 일자·교시·고사실을 골라 명렬표·좌석배치도·고사실 시간표를 바로 인쇄 (한 장 / 그 교시 모든 고사실 / 그 고사실 모든 교시)

## 개발자용
| 경로 | 내용 |
|---|---|
| `app/index.html` | 개발용 실행 파일 (더블클릭으로 바로 실행) |
| `app/js/core/` | 계산 로직 (불러오기·충돌·통계·자동 배치·고사실 배치) — 화면과 무관 |
| `app/js/ui/stepN_*.js` | 단계별 화면 (파일 1개 = 단계 1개) |
| `app/js/export/` | 엑셀 출력(`excel.js`, 시트 추가는 `TT.EXCEL_SHEETS`에 한 줄)과 미리 보기 |
| `app/css/style.css` | 디자인. 색은 맨 위 `:root` 변수만 바꾸면 됨 |
| `tools/build_single.py` | `python3 tools/build_single.py` → `dist/시험시간표.html` 한 파일로 묶기 |
| `tests/run_tests.js` | `node tests/run_tests.js` — `sample/2026_2_2.xlsx`(저장소에 없음)로 검증 |

학생 데이터(`sample/`, `*.xlsx`, 프로젝트 `.json`)는 `.gitignore`로 저장소에 올라가지 않습니다.
